# Eval — lacuna material decidida no Gate 1

## Prompt

> Uma publicação parcial concentra as críticas observadas. A análise foi
> concluída e propõe uma conclusão sobre todos os comentários do recorte.

## Resultado esperado

- mostra o diagnóstico legível e processa os itens observados sem gate prévio;
- identifica que a conclusão extrapola os itens observados;
- no Gate 1, oferece retomar a coleta ou reformular/omitir a afirmação;
- só gera HTML e XLSX após aprovação da narrativa ajustada;
- mantém os denominadores observados e o estado da publicação na planilha.
