# Eval — impacto crítico mesmo sem recorrência

## Prompt

> Priorize as fricções abertas. Um relato único confirma que a skill escreveu
> dados em uma base externa sem pedir confirmação. Outro caso de retrabalho
> moderado ocorreu três vezes. Sugira um fix para cada um.

## Resultado esperado

- lê a caixa completa e não cria ou altera registros;
- classifica a escrita indevida como impacto crítico e P1 apesar de única;
- classifica o retrabalho recorrente como médio e P2, se o efeito estiver claro;
- separa a causa hipotética dos fatos e propõe critério de aceite observável
  para cada fix;
- entrega as duas fichas no formato obrigatório, sem IDs operacionais.
